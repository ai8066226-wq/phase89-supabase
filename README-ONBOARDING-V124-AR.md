# شاشة البداية في مَسار 3.0.1

تظهر شاشة ترحيب متحركة قبل اختيار الحساب أو تسجيل الدخول للضيف عند أول تشغيل على الويب أو داخل تطبيق Android. تعرض الشاشة «بدء البرنامج»، «تعليمات الاستخدام»، ورابط «سياسة الخصوصية». فتح التعليمات أو السياسة لا يُكمل البداية؛ يحفظ التطبيق الإكمال محليًا فقط بعد الضغط على «بدء البرنامج».

- يتجاوزها المستخدم الذي لديه جلسة دخول قائمة.
- تُستخدم الشاشة نفسها في بوابات العميل والكابتن ومزود الخدمة، مع مفتاح تخزين مشترك `masar.firstRun.completed.v1`.
- تعتمد الحركة على CSS وSVG محليين، وتراعي إعداد تقليل الحركة في النظام.
- إذا لم تصل نتيجة الجلسة خلال خمس ثوانٍ، تظهر شاشة البداية لتجنب شاشة فارغة؛ وتُغلق تلقائيًا إذا تبيّن لاحقًا أن المستخدم مسجل الدخول.
- يفتح زر الخصوصية الصفحة المحلية `privacy.html`. الرجوع منها يعيد إلى التطبيق دون اعتبار البداية مكتملة.

للتحقق: افتح `index.html` في متصفح بلا بيانات محلية، جرّب التعليمات والرجوع، افتح السياسة ثم ارجع، واضغط «بدء البرنامج». أعد فتح الصفحة وتأكد من عدم تكرار الشاشة. كرر الدخول مع جلسة مسجلة في بوابتي الكابتن والخدمات.
