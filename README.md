# آمرني 2.9.2 / Android 119 — رصيد الكابتن والطلبات القريبة

تحديث بوابات العميل والكابتن والخدمات والإدارة: رسوم المنصة والشحن للكابتن وحده؛ صفحات العميل ومزود الخدمة لا تطلب رصيدًا أو اشتراكًا. بطاقة طلب واضحة فوق خريطة الكابتن تعرض الأجرة، نقطتي الاستلام والوصول، المسافة، رسوم القبول وزري القبول والإخفاء. يتدرج عرض الطلب للكباتن الأقرب ضمن 10 كم بفاصل 12 ثانية، ويحسم الخادم أهلية القبول ويمنع تجاوز ترتيب الدور. يمكن للإدارة التحكم في شحن الكابتن بالكرت أو التحويل.

## خطوات التشغيل

1. نفّذ ملف `supabase/migrations/20260927_captain_wallet_nearest_dispatch_v119.sql` على مشروع Supabase المعتمد. هذا مطلوب لتفعيل الرسوم والتوزيع الآمن على الخادم. إذا طبقت ترحيل v117 السابق لاحقًا، أعد تطبيق v119 بعده.
2. انشر محتويات هذا المجلد كاملة بما فيها `driver-offers.css` و`sw.js`.
3. مشروع Android المطابق يحتوي المحتويات نفسها ضمن `assets/www` وبرقم إصدار 119.

تعتمد أهلية الطلب على GPS محدث خلال 90 ثانية والتصنيف وحالة الاتصال. لا يبدأ خصم رسوم الكابتن إلا عند نجاح قبوله للطلب؛ لا تخصم رسوم منصة من العميل أو مزود الخدمة. عمليات الشحن السابقة تبقى في السجل التاريخي.
