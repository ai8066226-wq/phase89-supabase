# آمرني v110 — بطاقة رمز التحقق

- استُبدلت نافذة `prompt` الخاصة برمز التحقق ببطاقة داخلية احترافية تحمل هوية آمرني.
- لا يظهر عنوان WebView أو النص `appassets.androidplatform.net` عند إدخال رمز الرحلة.
- البطاقة مخصصة لرمز بدء رحلة التكسي، ورمز استلام الطلب من النشاط، ورمز تسليم الطلب للعميل.
- الرمز مكوّن من أربعة أرقام، مع انتقال تلقائي بين الحقول ودعم اللصق.
- تدعم البطاقة الأرقام العربية `٠١٢٣` والفارسية `۰۱۲۳` والإنجليزية `0123` وتحولها داخليًا إلى صيغة موحدة.
- يمكن الإلغاء أو الرجوع من البطاقة من دون إرسال رمز ناقص.
