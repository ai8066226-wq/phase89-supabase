# إدارة الحسابات والخمول — Karwa v111 / 2.8.21

## ما تمت إضافته

- دليل حسابات داخل لوحة الإدارة للعملاء والكباتن ومزودي الخدمات.
- معرفة آخر نشاط من آخر تسجيل دخول أو آخر استخدام مسجل للتطبيق، أيهما أحدث.
- فلاتر للخمول: شهر، شهران، 3 أشهر، 6 أشهر، وسنة.
- تصفية حسب نوع الحساب، مع تصفية الخدمات الأخرى حسب الصنف.
- زر حذف للكابتن داخل بطاقته، وزر حذف لصاحب الخدمة داخل بطاقته، وحذف العملاء من دليل الحسابات.

## الحذف النهائي

تظهر بطاقة تأكيد احترافية، ولا يبدأ الحذف إلا بعد كتابة العبارة `حذف نهائي`. ينفذ الخادم حذفًا كاملًا يشمل:

- حساب Supabase Auth وجلسات تسجيل الدخول.
- الملف الشخصي وطلب الانضمام وملف الكابتن أو النشاط.
- الطلبات والرحلات وعناصر الطلبات المرتبطة.
- الرصيد وحركات المحفظة وطلبات الشحن.
- التقييمات والأجهزة ورموز الإشعارات.
- مستندات التوافق القديمة داخل `karwa_documents`.
- صور وملفات الحساب داخل التخزين.

## الحماية

- لا تعمل وظيفة الإدارة دون جلسة مستخدم صحيحة وصلاحية `admin` من قاعدة البيانات.
- يمنع الخادم حذف حساب الإدارة الحالي أو أي حساب آخر يحمل صلاحية إدارة.
- مفتاح الخادم السري يبقى داخل Supabase Edge Function ولا يضاف إلى ملفات الويب أو أندرويد.
