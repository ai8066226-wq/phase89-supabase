# إصلاح توصيل الطلبات اللحظي — v103

- إصلاح RLS في Supabase حتى يرى كابتن التوصيل الطلبات غير المعيّنة المطابقة لنوع خدمته ضمن 10 كم.
- يشمل توصيل الأغراض `parcel` والطعام `food` وتوصيل طلبات المطاعم والخدمات `serviceDelivery`.
- `serviceType=delivery` هو معيار التوجيه للكابتن سواء كانت المركبة دراجة أو سيارة.
- Realtime هو المسار الفوري، مع إعادة قراءة بعد تأكيد الاشتراك واحتياط تحديث كل 4 ثوانٍ لقوائم الطلبات فقط.
- زر موافقة مزود الخدمة يعرض رسم القبول، ويمنع المحاولة مسبقًا إذا كان الرصيد غير كافٍ مع رسالة واضحة بدل «تعذر تحديث حالة الطلب».
- تم اختبار RPC الخاص بموافقة المطعم داخل معاملة اختبارية: عند توفر الرصيد ينشئ `serviceDelivery` بنجاح، والكابتن طارق ال يونس يطابقه ويراه وفق سياسة الخادم.
