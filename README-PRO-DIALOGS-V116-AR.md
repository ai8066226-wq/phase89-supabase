# ديالوجات آمرني الاحترافية — v116 / 2.8.26

تم استبدال نوافذ المتصفح الافتراضية في جميع البوابات بديالوج موحّد يحمل هوية آمرني.

- تصميم متجاوب للجوال مع خلفية ضبابية وبطاقة واضحة وأزرار عربية.
- حالات مستقلة للتأكيد والتنبيه والإدخال والإجراءات الخطرة.
- استخدامه في تسجيل الخروج، الإلغاء، الحذف، الحظر، التنبيهات والعمليات المالية.
- تحقق داخل البطاقة من الحقول وعبارات التأكيد الحساسة.
- دعم لوحة المفاتيح والتركيز وخصائص الوصول.
- طبقة Android احتياطية تمنع إظهار عنوان `appassets.androidplatform.net` حتى لأي استدعاء قديم.
