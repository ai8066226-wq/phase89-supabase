# إصلاح v106 — التحكم بطرق شحن الرصيد

- إضافة مفتاح مستقل في الإدارة لطريقة التحويل اليدوي.
- إضافة مفتاح مستقل في الإدارة لكروت الشحن الرقمية.
- يمكن تشغيل الطريقتين معًا، تشغيل واحدة فقط، أو إيقافهما معًا.
- الإيقاف يطبق داخل Supabase، وليس مجرد إخفاء في الواجهة.
- بقاء طلبات التحويل القديمة ظاهرة للإدارة للمراجعة حتى إذا تم إيقاف استقبال طلبات جديدة.
- توليد كروت الشحن من قسم الشحن نفسه مع قيم سريعة تبدأ من 5,000 د.ع.
- العميل والكابتن ومزود الخدمة يرون فقط طرق الشحن المفعلة لحظيًا.
- كرت تم توليده أثناء تفعيل النظام لا يمكن استبداله أثناء إيقاف طريقة الكروت، ويعود صالحًا عند إعادة التفعيل إذا لم يكن قد استُخدم.
