# المرحلة 87 — صور الخدمات والمنتجات

أضيفت إدارة صور متكاملة لمزودي الخدمات:

- صورة واجهة مخصصة للنشاط.
- صورة مستقلة لكل منتج أو خدمة.
- تعديل العنصر الموجود وصورته دون حذفه وإعادة إنشائه.
- مكتبة جاهزة من 45 صورة للمأكولات والخدمات اليومية.
- قص تلقائي: 16:9 لصورة الواجهة و1:1 لصورة المنتج.
- تحويل تلقائي إلى WebP وضغط إلى 50 KB كحد أقصى.
- رفع الصور إلى Firebase Storage وحفظ الرابط داخل Firestore.
- حذف الصورة القديمة من التخزين عند استبدالها أو حذف العنصر بعد حفظ التغييرات.
- تنظيف الصور الجديدة تلقائيًا إذا فشل حفظ بيانات النشاط بعد رفعها.
- ظهور صور المنتجات والوجبات وصورة واجهة النشاط في صفحة العميل.

## النشر
يجب نشر `storage.rules` و`firestore.rules` مع ملفات الاستضافة حتى تعمل صلاحيات رفع وحذف الصور الجديدة.
