# إصلاح v101 — توحيد قوائم التسجيل

- إزالة تكرار حقل رقم الهاتف في إنشاء حساب «الخدمات الأخرى».
- منع `supabase-compat.js` من حقن حقل هاتف إضافي إذا كانت الصفحة تحتوي أصلًا على `registerPhone` أو `driverPhone`.
- توحيد الحقول الأساسية لإنشاء الحساب: البريد الإلكتروني، كلمة المرور، تأكيد كلمة المرور، الاسم، رقم الهاتف، ثم البيانات الخاصة بنوع الحساب.
- إضافة تأكيد كلمة المرور إلى حساب العميل والخدمات الأخرى مثل تسجيل الكابتن.
- إبقاء رقم الهاتف إلزاميًا مرة واحدة فقط (8–15 رقمًا) في كل مسار تسجيل.
