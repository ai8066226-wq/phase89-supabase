# إصلاح دخول الإدارة v95

السبب المرجح الذي تم عزله: ملفات خرائط Phase 90 الخارجية كانت محملة كسكربتات كلاسيكية قبل admin.js، لذلك أي بطء/حجب في unpkg يمنع تشغيل admin.js ويترك نموذج الدخول يعمل كـ HTML عادي.

- Leaflet يتم تحميله فقط بعد نجاح فتح لوحة الإدارة، مع jsDelivr ثم unpkg كخيار احتياطي.
- فشل الخريطة لا يمنع الإدارة من العمل.
- admin.js أصبح v95 لكسر الكاش.
