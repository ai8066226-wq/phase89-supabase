# إصلاح v104 — وصول الطلبات للإدارة لحظيًا

- إضافة إشعار فوري للإدارة عند إنشاء طلب تكسي أو توصيل أغراض أو توصيل طعام/خدمة.
- إضافة إشعار فوري عند إنشاء طلب مطعم/خدمة قبل موافقة مزود الخدمة.
- إبقاء إشعارات الشحن وتسجيل الكباتن والخدمات، وإضافة طلبات تغيير الجهاز.
- عرض طلبات المطاعم والخدمات المعلقة داخل لوحة «الطلبات الواردة لحظيًا» بدل اقتصارها على طلبات الكباتن.
- Supabase Realtime هو المسار الفوري، مع تحديث احتياطي كل 4 ثوانٍ عند تعطل WebSocket أو انتقال شبكة Android WebView.
- لا يتم إطلاق إشعارات على السجل الأول عند فتح لوحة الإدارة؛ فقط الطلبات الجديدة التي تصل بعد اتصال اللوحة.
