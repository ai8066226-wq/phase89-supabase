# كروة v108 — الأرصدة الفعلية والتقرير المالي

## الجديد

- عرض الرصيد الفعلي المتاح للعملاء والكباتن ومزودي الخدمات في لوحة الإدارة.
- فصل الرصيد المشحون عن الرصيد المجاني الصالح، مع عدم احتساب الرصيد المجاني المنتهي.
- جدول مالي لكل الحسابات مع البحث والتصفية حسب نوع الحساب.
- تقرير احترافي حسب اليوم أو 7 أيام أو 30 يومًا أو الشهر الحالي أو كامل الفترة.
- مؤشرات للمبيعات المكتملة ورسوم كروة وأرباح الكباتن ومبيعات الخدمات والشحنات وحركة المحفظة.
- تفصيل رسوم العميل والكابتن والمطعم والخدمات ورسوم نشر النشاط.
- تصدير التقرير بصيغة CSV والطباعة أو الحفظ PDF من المتصفح.

## أدوات الإدارة المالية

- **تصفير كل الأرصدة:** يجعل الرصيد المشحون والمجاني صفرًا لجميع حسابات العملاء والكباتن والخدمات فقط، ولا يغيّر حسابات الإدارة.
- **تصفير التقرير من الآن:** يبدأ فترة مالية جديدة من وقت التنفيذ مع إبقاء الطلبات القديمة محفوظة.
- **حذف سجلات الشحن والمحفظة:** يحذف طلبات الشحن وحركات المحفظة وأقفال طلبات الشحن ويبدأ التقرير من جديد، ولا يحذف الطلبات أو الرحلات أو طلبات الخدمات.

كل عملية حساسة تتطلب كتابة عبارة تأكيد، وتعمل من حساب مدير معتمد فقط. تُقسّم العمليات الكبيرة إلى دفعات تقل عن حد عمليات Supabase الحالي.

## التوافق

- لا تحتاج هذه المرحلة إلى دالة RPC جديدة؛ تستخدم مسار العمليات الحالي المحمي بفحص صلاحية المدير.
- تم تحديث قواعد Firestore الاحتياطية للسماح للمدير فقط بحذف حركات المحفظة عند استخدام المسار القديم.
- الإصدار: `2.8.18`، ورقم Android: `108`.
