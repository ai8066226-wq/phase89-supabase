# صور الخدمات حسب الصنف — Karwa v112 / 2.8.22

## ما الجديد

- رفع صور واجهة النشاط وصور المنتجات أو الخدمات بصيغة JPG/JPEG أو PNG فقط.
- فحص التوقيع الحقيقي للملف، وليس الامتداد وحده، لمنع إضافة صيغة غير مدعومة.
- قص تلقائي لصورة الواجهة بنسبة 16:9 ولصورة العنصر بنسبة 1:1.
- تحويل داخلي إلى WebP وضغط تلقائي إلى 100KB كحد أقصى قبل الرفع.
- عرض حجم الصورة الأصلية والحجم النهائي بعد الضغط والأبعاد داخل المعاينة.
- تنظيم الصور في Supabase Storage حسب صاحب الحساب ثم صنف الخدمة ثم نوع الصورة.
- فرض حد 100KB ونوع WebP على حاوية `service-assets` في الخادم أيضًا.

تبقى الصور القديمة صالحة، ويُطبّق التنظيم الجديد عند رفع صورة جديدة أو استبدال صورة موجودة.
