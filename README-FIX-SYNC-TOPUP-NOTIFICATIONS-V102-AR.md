# إصلاح v102 — التسعيرة والشحن والإشعارات

- التسعيرة العامة تتزامن عبر Supabase Realtime مع فحص احتياطي كل 12 ثانية وعند عودة التطبيق للواجهة/الإنترنت.
- مزامنة صف `app_settings/pricing` تلقائيًا مع `appSettings/pricing` في قاعدة البيانات.
- منع أكثر من طلب شحن واحد بحالة pending لكل مستخدم على مستوى قاعدة البيانات، إضافة إلى القفل الذري الموجود مسبقًا.
- إشعارات اعتماد/رفض الشحن للعميل والكابتن ومزود الخدمة.
- إشعارات الإدارة لطلبات الشحن وطلبات تسجيل الكباتن والخدمات الجديدة.
- جميع إشعارات مركز الإشعارات يمكن حذفها منفردة، مع زر حذف كل الإشعارات.
