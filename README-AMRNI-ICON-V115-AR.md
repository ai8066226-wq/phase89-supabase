# أيقونة آمرني الكلاسيكية — v115 / 2.8.25

تم الحفاظ على تكوين الأيقونة السابقة: السيارة، علامة الموقع الذهبية، الطريق ومعالم المدينة.

التغييرات المقصودة فقط:

- تحويل اللون الأخضر إلى درجات الفيروزي والتركواز المطابقة لهوية آمرني الجديدة.
- تعزيز الخلفية الكحلية مع الإبقاء على الذهبي في علامة الموقع والعناصر البارزة.
- استبدال الاسم القديم بالنص الدقيق «آمرني» و`AMRNI`.
- إنتاج مقاسات 768 و512 و192 بكسل للويب وPWA وAndroid.

بقي معرّف Android الداخلي `com.razi.karwa` دون تغيير حتى تُثبت النسخة كتحديث فوق التطبيق الحالي.
