# هوية تطبيق آمرني — v114 / 2.8.24

تم تغيير الاسم الظاهر للمستخدم من الاسم السابق إلى **آمرني** في:

- تطبيق العميل والكابتن والخدمات الأخرى.
- لوحة الإدارة وشاشات الدخول والتحقق.
- اسم تطبيق Android وشاشة البداية ورسائل الخطأ.
- الإشعارات وقنوات الاتصال بالخلفية.
- بيانات PWA ووصف التطبيق المثبت من المتصفح.
- اسم مستلم الشحن الظاهر للمستخدم.

## الأيقونة الجديدة

الأيقونة الجديدة تجمع بين خلفية زرقاء–فيروزية، علامة موقع ذهبية وحرف «آ» أبيض مع علامة إنجاز ذهبية. جرى إنتاج المقاسات 192 و512 و768 بكسل من أصل SVG واحد لضمان الوضوح.

## التوافق

بقي معرّف Android الداخلي `com.razi.karwa` وأسماء واجهات الربط البرمجية كما هي. هذا مقصود حتى تُثبت v114 كتحديث طبيعي فوق النسخة الحالية وتحافظ على جلسات المستخدمين وبياناتهم.
