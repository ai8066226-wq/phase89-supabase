# المحافظات العراقية وتشغيل الخدمة — Karwa v113 / 2.8.23

يستخدم التطبيق قائمة موحدة من 19 محافظة عراقية عند تسجيل الكابتن أو مزود الخدمات الأخرى:

بغداد، البصرة، نينوى (الموصل)، أربيل، النجف، كربلاء، كركوك، دهوك، السليمانية، الأنبار، بابل، ديالى، ذي قار، صلاح الدين، واسط، ميسان، المثنى، القادسية (الديوانية)، حلبجة.

## تحكم الإدارة

- قسم مستقل باسم «تشغيل المحافظات» يعرض الحالة الفعلية لكل محافظة.
- أزرار لتفعيل الكل أو إيقاف الكل، مع تأكيد إضافي عند إيقاف العراق بالكامل.
- إيقاف محافظة يمنع التسجيل وإعادة إرسال الطلبات والنشر وقبول الطلبات فيها.
- الكابتن المتصل في محافظة أوقفتها الإدارة يتحول إلى غير متصل فورًا.
- النشاط المنشور في المحافظة المتوقفة يصبح غير نشط ويختفي من واجهة العميل، ولا يُعاد نشره تلقائيًا عند إعادة التفعيل.
- الحسابات والطلبات والبيانات لا تُحذف عند إيقاف المحافظة.

## حماية الخادم

تطبق هجرة Supabase الموجودة في:

التحقق داخل قاعدة البيانات، وتمنع الواجهة القديمة أو الطلب المباشر من تجاوز قرار الإدارة. كما توحد القيم التاريخية مثل «الموصل» إلى «نينوى» و«الديوانية» إلى «القادسية».

## أقسام لوحة الإدارة

بطاقات مركز المتابعة تفتح قسمًا واحدًا في كل مرة. يمكن كذلك فتح أو إغلاق القسم من عنوانه باستخدام النقر أو لوحة المفاتيح، ويُحفظ آخر قسم فتحه المدير خلال الجلسة.
